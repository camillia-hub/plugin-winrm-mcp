# WinRM MCP

Runs PowerShell on Windows hosts over WinRM. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/winrm-mcp

Installs from the Camillia hub as `winrm-mcp-b30eca`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
